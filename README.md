# Full-Stack Remote Job Prep Mentorship (Codementor Demo)

Sample long-term mentorship plan for **full-stack (Node.js) remote job prep**. Topic/skill demo only — no personal client data.

**Rate context:** typically US$60/hr · long-term mentoring · Node.js / full-stack focus

---

## Mentorship goal

Help you become **hireable for remote full-stack roles**: solid Node.js + frontend fundamentals, a portfolio project you can defend in interviews, and a repeatable interview/debug practice loop.

## How we’ll work (long-term)

| Phase | Focus | Deliverable |
|-------|--------|-------------|
| 1. Baseline | JS fluency, Git, HTTP, SQL basics | Skills map + weekly plan |
| 2. Backend | Node.js, Express, REST, auth, DB | Small API with tests |
| 3. Frontend | React (or your stack), state, API wiring | UI that consumes your API |
| 4. Portfolio | Deployed full-stack app + README | Interview-ready project |
| 5. Interview loop | System design lite, coding drills, mock calls | Confidence + talk track |

Sessions: pair-programming first, short concept bites second. You drive the keyboard; I unblock and push quality.

### Typical session shape
1. **Check-in (5 min)** — blockers since last time  
2. **Pair work (40–50+ min)** — feature, bug, or drill  
3. **Recap (5–10 min)** — homework + “definition of done”
